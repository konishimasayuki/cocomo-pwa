# ココモ法 資金管理 PWA（競艇向け）

ベットA / ベットB の2枠を切り替えながら、ココモ法(前回+前々回のベット額を賭け、負けたら数列を進め、勝ったらリセット)で
次のベット額を自動計算するツールです。データはUpstash Redisに保存され、複数端末から見ても同じ状態になります。

## 画面構成
- 中央下タブ「競艇」= ホーム（次のベット額・勝ち/負け入力）
- 左タブ「履歴」= 全ベットの記録（日付・会場・レース・スロット・結果・収支）
- 右タブ「設定」= 基本ベット単位、推奨最低オッズ、リセット

## セットアップ

### 1. 依存関係のインストール
\`\`\`bash
npm install
\`\`\`

### 2. Upstash Redisを用意する
1. https://upstash.com にログイン（なければ無料アカウント作成）
2. 「Create Database」→ Redis を選択（Regional でOK）
3. 作成後の画面で **REST API** の `UPSTASH_REDIS_REST_URL` と `UPSTASH_REDIS_REST_TOKEN` をコピー

### 3. 環境変数を設定
`.env.example` を `.env.local` にコピーして、上でコピーした値を貼り付けます。

\`\`\`bash
cp .env.example .env.local
\`\`\`

### 4. ローカル起動
\`\`\`bash
npm run dev
\`\`\`
http://localhost:3000 で確認できます。

## Vercelへのデプロイ
1. このフォルダをGitHubリポジトリにpush
2. Vercelで「Import Project」→ 該当リポジトリを選択
3. Vercelの Environment Variables に `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` を追加
4. Deploy

## スマホへのインストール（PWA）
- **iPhone(Safari)**: デプロイ後のURLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android(Chrome)**: URLを開く → メニュー → 「アプリをインストール」

## ココモ法の数列について
初期数列は `[1, 1]` で、負けるたびに直前2項の和を数列に追加します（1, 1, 2, 3, 5, 8, 13...）。
勝った時点で数列は `[1, 1]` にリセットされ、次のサイクルが始まります。
この方式は配当3倍前後を想定した設計のため、設定画面の「推奨最低オッズ」でベット時に注意喚起する仕組みにしています
（強制的にブロックはしません）。
